# Calendar View — Demo Project

Simple React + TypeScript + Tailwind demo implementing a Month View calendar with basic event add.

## Run locally

1. npm install
2. npm run dev
3. Open http://localhost:5173

This project is a simplified, student-friendly subset of the full assignment (month view, event add/save in-memory). It includes:
- Month view grid (42 cells)
- Event add modal (title, start/end, color)
- Responsive layout with Tailwind

Storybook and full week view are omitted in this demo for brevity. If you want the full assignment-level project with Storybook and week view, tell me and I'll generate that next.
